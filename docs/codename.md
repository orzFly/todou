# Codename: todou

## Decision

The project is named **todou**, from "ToDo + u" — a bilingual pun: it reads as
"To-Do" in English while sounding exactly like 土豆 (tǔdòu, "potato") in
Chinese.

## Date

2026-08-11

## Context

这个项目是一个 todo list 应用。起名时在两个谐音候选之间纠结：
`todou` 和 `tudou`，两者读音都是「土豆」。

## Decision path

- **tudou**：即拼音「土豆」，更偏向土豆本身的萌感，接地气、圆滚滚，
  图标可以直接用一个胖乎乎的土豆。
- **todou**：ToDo + u（也可以理解成法语 doux「温柔」），拼写上一眼能看出
  是待办工具（To-Do），读音上又保留了「土豆」的调皮劲儿，双关更巧妙、
  更有设计感。

最终选择了 **todou**：功能属性（To-Do）和萌感（土豆）两者兼得。

## Final interpretation

todou = To-Do + u，读作「土豆」。一个像土豆一样朴实可爱的待办清单应用——
把任务当成土豆，一颗一颗挖出来。吉祥物构想：一颗顶着水花的土豆 🥔🌊。
