## What's new

- **You can see which agents are watching.** An agent's `todou watch`,
  `issue watch`, `spec wait` or `question wait` now shows up live in the web:
  on the projects home and the list and board toolbars for a project-wide
  watch, and on the card for a card-level one — a live dot on a watching
  assignee, an eye for everyone else, and a line above the comment box.
  Hover or tap for who is waiting, on what, and since when.
- **`--invisible` keeps a watch off that list.** It gets the same feed;
  nobody sees it there.

## Fixed

- **A reference chip's title wraps with the text around it**, instead of
  jumping whole onto the next line and leaving a gap behind it.

## Breaking changes

None.

## Upgrading

- **No migration, no configuration change.** The web UI ships with the
  server.
- **Only an upgraded CLI is listed.** An older CLI keeps watching a new
  server as before, just without appearing; a new CLI against an older
  server watches as before and is never listed.
- **The list lives in server memory.** A server restart empties it until the
  watches reconnect on their own.
