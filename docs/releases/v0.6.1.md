## What's new

- **A Codex conversation can follow the tracker.** `todou issue watch` and
  `todou watch` take `--follow=codex`, and new comments, spec reviews and
  answers arrive in that conversation as a turn. A plain `codex` TUI works as
  well as the App; `todou agent can-i-follow` says how this one is reached.
  Setup in `docs/codex.md`.
- **A ```` ```mermaid ```` fence draws as a diagram**, in bodies, comments and
  specs, following the light or dark theme. A diagram that does not parse
  stays a code block with mermaid's error under it.
- **A question card points at what is left.** Pressing the waiting submit
  scrolls to the first unanswered question; **Skip unanswered…** sends what
  you have and declines the rest, after a confirm.

## Fixed

- **Spec review drafts stop vanishing.** One draft an older build had saved
  could hide all the others until the next one overwrote them, and two tabs
  on one spec deleted each other's drafts.
- **Typing in a sticky composer no longer scrolls the page** one step per
  keystroke, on cards and in spec review.
- **A `#comment-` link stays on its comment** while images and attachments
  above it finish loading, instead of ending up off-screen.
- **The back link on a card keeps the list's filters**, closed cards
  included, where it sometimes fell back to the project's default list.
- **Opened folds in a spec review stay open** when a comment is staged inside
  them or discarded again.

## Breaking changes

None.

## Upgrading

- **No migration, no configuration change.** The web UI ships with the
  server; the API is untouched, so either CLI pairs with either server.
- **`--follow=codex` was verified against Codex CLI 0.154.0.** Both channels
  it uses are young Codex interfaces that later releases may change.
