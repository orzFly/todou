## What's new

- **`/me` actions.** `/me is reviewing` on a line of its own in the comment
  box posts one line that reads after your name; `todou me 16 is reviewing`
  does the same from the CLI. They mark a card unread the way events do,
  not the way comments do.
- **Delete an attachment.** The uploader can delete their own file and a
  writer anyone's, from the web or with `todou attach delete`. Both list the
  bodies and comments that still link the file before deleting it.
- **Pasting formatted text keeps its formatting.** Links, emphasis, lists,
  tables and code come in as Markdown. A toolbar after the paste switches it
  to plain text or a quote, and the keyboard button beside attach lists the
  shortcuts.
- **`todou upgrade`** replaces the running CLI with a newer build, checked
  against the GitHub release's SHA256SUMS. A build GitHub does not carry is
  installed only after you confirm.
- **`todou watch --mine`** delivers only the cards assigned to your account
  and the entries that @-mention it.

## Fixed

- **Phones get their screen back.** The header slides away while you read,
  a spec page pins one toolbar row instead of five, the comment box stays
  above the keyboard, and a touch that starts a scroll no longer opens a
  row's menus.
- **iOS pinyin no longer leaves stray letters** when a word wraps at the end
  of a line.
- **Large text attachments open in the viewer.** Under 1 MiB they no longer
  freeze the tab (a 1 MiB log took 9.3 s, now 0.36 s). From 1 to 10 MiB they
  preview on request; above that, Download.
- **Watcher stacks show current names and avatars**, without a reload.
- **Completion popups are no longer cut off** in Safari or inside dialogs.

## Behaviour changes

- **"Quiet until new activity" is now a one-shot snooze.** Once someone else
  acts on the card it notifies again, and stays that way. A card that already
  had other people's activity since it was quieted starts notifying on
  upgrade.
- **Files dropped into an editor are drafts until the text is sent.** Only
  the uploader sees them, and unsent drafts are deleted after 24 hours.
  `todou attach` still attaches at once.
- **The server deletes abandoned direct uploads by itself** on the s3
  backend, hourly, once they are 24 hours past expiry. `todou-server storage
  gc` no longer needs a timer.
- **A formatted paste becomes Markdown.** Mod-Shift-V still pastes plain
  text.

## Breaking changes

None.

## Upgrading

- **Server first.** Three migrations run on first start and only add: a
  draft flag on attachments, a comment kind, and a table of the projects
  holding drafts. Nothing to run by hand, no configuration change.
- **An older CLI works against this server.** It shows a `/me` action as a
  plain comment.
- **A 0.6.6 CLI against a 0.6.5 server** works except for the new commands:
  `todou me` is refused with 422, `todou attach delete` fails with 404, and
  `todou watch --mine` warns once and delivers everything. Read off the code,
  not run.
- **omp and Pi users: run `todou integration install-all`** after upgrading
  the CLI. Both integrations gained a `profile` setting on their watch tool,
  and `todou integration status` reports the old ones as stale.
