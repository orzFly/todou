## What's new

- **Select many, act once.** Checkboxes on the issue list, board and
  attachments: set status, labels or assignees, mark read, drag together,
  download as one tar, delete.
- **Compare pictures.** Spec diffs draw a swapped image or a changed mermaid
  diagram side by side; `![](a.png) → ![](b.png)` pairs two images anywhere.
- **Framed code blocks** with Copy, collapse past 30 lines, and download
  when the fence names a file. Patches fold per file.
- **Act as your agents with your own token** (`agents:act` scope,
  `todou login --profile <name> --act-as <agent>`).
- **Withdraw a question** from the web or `todou question withdraw`.

## Also

- **Spec pages stay on the version in their address** and point to the
  newer one; staged review comments carry over.
- **Quote reply follows selected text**, files land in the text where you
  add them, and the image viewer's zoom pauses at contain, cover and 100%
  and no longer slides or, under reduced motion, jolts the image while the
  frame resizes.
- **`todou issue watch-add` / `watch-remove`**; writes warn about mermaid
  diagrams that do not parse; watches hold references and attachments up to
  5 minutes and batch over 15 s instead of 60 s.
- **Operators:** sign-in admission for oidc and forward (off by default),
  `todou-server user promote` / `demote`, a stable-id `subject_header` for
  forward auth, and a security pass.

## Behaviour changes

- **Moving a card needs admin in both projects.**
- **Blocking a card in another project needs `issue.block` there.**
- **todou cannot be framed**, and scripts injected by a proxy or CDN are
  refused.
- **Agent tokens cannot create tokens.**
- **JSON routes answer 415 to other content types.**

## Breaking changes

- **`todou spec review --approve` needs `--version <N|latest>`.**
- **`TODOU_TOKEN` is not sent to a server named only by a directory
  `.todou.toml`**; name it with `TODOU_SERVER` or `--server`.

## Upgrading

- **Server first; either order is safe.** Seven additive migrations, run
  with `todou-server migrate` on PostgreSQL as usual.
- **List your proxy in `http.trusted_proxies`**, or all users share one CLI
  login rate cap.
- **Old CLI, new server:** works; `question wait` misses a withdrawal.
- **New CLI, old server:** `watch-add`, `watch-remove` and
  `question withdraw` 404; `login --act-as` refuses. Read off the code.
