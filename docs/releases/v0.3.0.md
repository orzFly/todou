## What's new

- **Project-wide search** — issue titles and bodies, comments, and each spec's
  newest version in one query; the last two were unreachable before. Terms are
  ANDed substrings, so a Chinese query needs no tokenizer and `WordDiff` is
  found inside `coalescedWordDiff`. `todou search`, plus a box in the web app.
- **Cross-project issue references** — `slug#12`, `slug/12`, and a bare
  `PREFIX-12` with exactly one holder all resolve and notify, in bodies,
  comments and spec documents alike.
- **A restorable trash** — deleting a card keeps everything hanging off it,
  leaves it readable only to its author and the project's admins, and Restore
  brings the card and every inbound link back. Numbers are never recycled.
- **A project can change its slug** — every previous spelling keeps routing, so
  attachment URLs and links in old comments survive; claiming a slug that still
  routes somewhere needs an explicit reclaim.
- **Getting the CLI onto a new machine** — the deployment serves the builds it
  was made from at public, checksummed `GET /api/cli`, and `login --no-browser`
  is a real device flow now, so a browser elsewhere can authorize it.

## CLI

- **The spec review gate is one command** — `spec push … --wait` pushes a
  version and blocks until it is judged, `spec wait <n>` re-enters that wait.
  The last line reads `approved`, `changes requested` with the annotation
  count, or `feedback` when somebody wrote without judging.
- **`--forever` on every wait** (`issue watch`, `watch`, `question wait`) — two
  endings only, entries or a fatal error. Timeouts re-arm and outages ride out
  inside the call, re-draining from the cursor it already holds.
- **Batch forms** — `issue view 12 15 23`, and `issue edit 12 15 23 --status
  Next` which reads every card before writing any; `--status` and `--label`
  take repeated or comma-split lists.
- **New reads** — `search`, `spec list`, `comment view`, `issue events`,
  `project members`, `attach list`/`download`, `config show` (the resolved
  configuration, never a token value), and `api` for whatever is left.
- **Fewer papercuts** — gh's flag spellings, `issue update`/`status`/`move`
  aliases, did-you-mean instead of an unknown-command wall, labels created on
  the spot by any write, `issue view --brief`/`--timeline`/`--last`, and a
  guard for a `--body` that is really a filename.

## Web

- **The spec page was rebuilt** — rendered-versus-source and comparing are
  independent controls, so a version reads as whole source with no baseline;
  diffs are word-level, and the toolbar and file rail float while you scroll.
- **Inline annotation anchors** — an annotation lands on a word, remaps across
  versions, and can be edited rather than discarded.
- **One editor on all seven markdown surfaces**, with issue-reference
  completion and slash commands. A slash command is an ordinary line of the
  draft, so deleting the line cancels it and a misspelling stays in the body.
- **Smaller things** — a project search page, the trash as a mode of the issue
  list plus a Danger zone on the card, renaming a project from settings, unread
  counts on every project-switcher row, and a floating issue title.

## New endpoints

`GET /projects/{slug}/search`; `DELETE /projects/{slug}/issues/{number}` and
`POST …/restore`; `POST …/issues/{number}/commands`;
`GET /projects/{slug}/comments/{commentId}`; `GET /me/reference-directory`;
public `GET /api/cli` and `GET /api/cli/{name}`; `/api/auth/cli/requests…` for
the device flow. Additive fields: `ref_prefix` on `POST /projects`, `slug` on
`PATCH /projects/{slug}`, and a cursor on write and spec responses.

## Behaviour changes

- **Pagination cursors are compact** — 18 characters where 67 were spent. Old
  cursors decode forever, by contract; a *new* one sent to an older server
  fails loudly rather than mispaging, which matters only during a rollback. A
  list cursor minted under one sort key and used under another is a 422 now
  instead of a quietly wrong page.
- **New projects get all seven statuses** (Backlog through Done) rather than
  three, with Todo as the default. `todou status init` adds what an older
  project is missing and syncs colors; a drifted category is reported, not
  changed.
- **Two smaller defaults moved**: a person is named by their display name now,
  falling back to the login and carrying `@login` where two people could share
  a name; and an attachment link opens inline instead of downloading — mapped
  at render time, so old comments benefit and the API's own `url` is unchanged.

## Breaking changes

Two, both on the CLI side; no endpoint or flag was removed.

- **`todou watch --json` is NDJSON** — the `{items, next_cursor}` envelope is
  gone: one record per line, closed by a `{"type":"cursor",…}` record. Take the
  cursor with `jq -r 'select(.type=="cursor").next_cursor'` and the entries
  with `jq 'select(.type!="cursor")'`. Most callers want the default rendering
  instead: one readable line per entry, comment bodies included.
- **An empty `--poll` exits 0**, not 3 — a finished check is a success whether
  or not it found news, so the `; true` around every cursor bootstrap can go. A
  *blocking* watch's timeout still exits 3.

## Upgrading

1. **Five migrations run on first start** — two per project (the trash columns,
   `pg_trgm` and its trigram indexes) and three system-wide (the cross-project
   prefix mirror, CLI auth requests, slug history).
2. **PostgreSQL needs `contrib` and a UTF-8 ctype.** The project migration runs
   `CREATE EXTENSION IF NOT EXISTS pg_trgm` and stops without contrib; and
   under `lc_ctype=C` a multi-byte character is not a word character, so every
   Chinese query falls back to scanning — correct answers, silently slow. Check
   `SELECT datctype FROM pg_database WHERE datname = current_database()`.
   PGlite links the extension in and needs neither.
3. **Server before CLI.** A 0.3.0 CLI's compact cursor is rejected outright by a
   0.2.0 server; an old CLI against the new server is unaffected.
4. **The image carries the five CLI builds** and serves them by default, taking
   it from roughly 67 MB to 169 MB compressed. Checkout deployments are handed
   them from a development machine with `scripts/push-cli.sh`, whose update
   script now refuses to deploy a commit no drop names.
