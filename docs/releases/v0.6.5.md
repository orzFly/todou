## What's new

- **All references for a card.** More actions → All references lists the
  cards linking to this one and the cards it links to, each at its current
  address. `todou issue refs` prints the same.
- **Your agents' tokens on Personal tokens.** Switch between User, Agents and
  All, and issue or revoke a token for any active agent you own from the same page.
- **Change status from the inbox.** Inbox rows carry the status menu, with
  the card's assignees and watchers beside it.
- **Settings are split into categories**, for your account and for each
  project, every category at its own address.
- **Projects without an uploaded icon get a colour of their own**, picked
  from the slug. Settings → Appearance switches them back to monochrome, and
  can open external links in a new tab.

## Fixed

- **The image viewer grows with the zoom**, up to its maximum height, and
  animates its size changes. It holds still while the pointer is on its
  controls, so paging and zooming no longer move the buttons away.
- **Reference chips follow the card they name.** A card closed, renamed or
  deleted elsewhere updates in place, without a reload.
- **A reference copied from another card notifies its target**, the way a
  typed one does.

## Behaviour changes

- **Project autolinks open in the same tab by default**, where they always
  opened a new one. Turn on "Open external links in a new tab" for the old
  behaviour, which then covers every external link.
- **Fallback project icons change look**: coloured gradients instead of one
  grey square, and the large REF watermark on project cards is gone.

## Breaking changes

None.

## Upgrading

- **No migration, no configuration change.**
- **Either CLI pairs with either server**, except `todou issue refs`, which
  needs a 0.6.5 server; against 0.6.4 it fails with 404. Read off the code,
  not run.
