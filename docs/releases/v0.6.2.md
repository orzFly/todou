## What's new

- **Patches draw as diffs.** `.patch` and `.diff` attachments and
  ```` ```diff ```` fences render file by file, under each commit's subject,
  author and message, with a file list that jumps to a file and a Raw toggle
  back to the text. Text that does not parse as a diff stays as written.
- **Images zoom and pan in the attachment viewer.** Wheel or pinch to zoom,
  drag to pan, click to switch between fit and actual pixels. The zoom menu
  also picks a black or checkerboard background and smooth or pixelated
  scaling, remembered per browser.
- **Assignees from the issue list, labels and assignees from the board**,
  without opening the card.
- **A question can be answered in a floating window.** In desktop Chromium
  and Firefox, a question card pops its form out into an always-on-top
  window; drafts survive the move both ways.
- **The empty comment composer folds** to a one-line box on desktop and a
  Comment button on phones, until you start writing.

## Changed

- **`--follow=codex` always delivers as a new turn.** Activity arriving while
  Codex works waits for that turn to end, where it used to land inside the
  running turn and an agent finishing one card could stop without acting on
  the rest. For an urgent stop, use the conversation directly.

## Fixed

- **A card opens at its end and stays there** while images above it finish
  loading; so do New messages, following a new item, and jumping to a
  question or a spec change.
- **Quick label and assignee toggles all stick.** A second toggle made
  before the first answered dropped the first.
- **Avatars on list rows and board cards stay put** when the assignee icon
  appears on hover.
- **A list that is wholly new in a spec diff keeps its indent**, so its
  markers no longer draw over the change bar.

## Breaking changes

**`TODOU_CODEX_SOCKET` no longer does anything.** `--follow=codex` reaches
Codex only through `codex queue`; a watch that relied on the App Server
socket alone now needs `codex` on PATH or `TODOU_CODEX_BIN`, and refuses to
start without one.

## Upgrading

- **No migration, no configuration change.** The server is unchanged apart
  from the web UI it ships, so either CLI pairs with either server.
- **The Codex change is in the CLI.** Until a machine upgrades its CLI, its
  watches keep delivering into the running turn.
