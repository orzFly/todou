## Security update

- **The runtime moves to Node 26.12.1, a security update.** Upgrade
  promptly.
- **The compiled CLI binaries are rebuilt on Deno 2.9.8.** `todou.cjs`
  still runs on Node 22 and later.

## Breaking changes

None.

## Upgrading

- **Docker: pull the new image.** It runs Node 26; nothing else to do.
- **systemd/mise hosts (`docs/deploy.md`): switch the host
  to Node 26 yourself.** Pulling this release does not change the node
  your service runs. As the service user, before the usual update:

  ```bash
  mise use -g node@26
  node --version    # v26.12.1 or later
  ```

  Then run your update script as usual: its `pnpm install`, `pnpm build`
  and service restart all pick up Node 26 through the mise shims.
- **No migration, no configuration change.** Either CLI pairs with either
  server.
